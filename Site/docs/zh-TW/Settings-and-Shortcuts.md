# 設定與快速鍵

設定會在變更時立即儲存，沒有儲存按鈕。它們與介面語言、上次開啟的分頁一起存放在程式的設定資料夾中。

## 應用程式

- **版本** 與 **平台** 為唯讀。
- **語言** 會立即切換介面。*系統預設* 會跟隨作業系統；預設為英文。
- **開啟 yafm:// 連結** 會為目前使用者註冊 `yafm://` 連結；開啟期間，程式每次啟動都會修復此登錄。
- **重新開啟先前開啟的分頁** 會還原分頁及各自顯示的資料夾。命令列指定的資料夾會取而代之。

## 色彩

- **預設集** 會同時套用強調色與次要色。內建八組。
- **新增預設集** 會用你指定的名稱儲存目前的顏色組合；`×` 可移除已儲存的預設集。預設集存放在設定檔中，
  不會被翻譯。
- **強調色** 與 **次要色** 可選擇任何顏色，色塊旁會列出最近使用的顏色，方便快速回復。
- **重設色彩** 會回到預設的藍色與靛色。

## 檔案檢視

以下是尚未儲存自身檢視之資料夾的預設值：

- 預設模式（清單或格狀）、清單圖示大小與格狀磚塊高度。
- **選取核取方塊**、**按一下即開啟**、**刪除前確認**。
- **在影片預覽中播放音訊**、**自動播放影片預覽**。
- **清單下方的預覽面板**，以及要顯示哪些**欄位**。

資料夾會從標題列記住自己的模式、大小與排序方式；標示為 *全域* 的核取方塊與其他開關則套用到所有資料夾。

## 快速鍵

點一下組合鍵即可錄製新的組合，按 **重設** 會把所有動作還原為預設值。預設值如下：

| 動作 | 按鍵 | 動作 | 按鍵 |
| --- | --- | --- | --- |
| 上一頁 | `Alt+←` | 下一頁 | `Alt+→` |
| 上一層 | `Alt+↑` | 主資料夾 | `Alt+Home` |
| 搜尋 | `Ctrl+F` | 編輯位置 | `Ctrl+L` |
| 新增分頁 | `Ctrl+T` | 關閉分頁 | `Ctrl+W` |
| 下一個分頁 | `Ctrl+Tab` | 上一個分頁 | `Ctrl+Shift+Tab` |
| 複製 | `Ctrl+C` | 剪下 | `Ctrl+X` |
| 貼上 | `Ctrl+V` | 復原 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` | 全選 | `Ctrl+A` |
| 反向選取 | `Ctrl+Shift+A` | 開啟 | `Enter` |
| 新增資料夾 | `Ctrl+Shift+N` | 重新命名 | `F2` |
| 移至資源回收筒 | `Del` | 永久刪除 | `Shift+Del` |
| 屬性 | `Alt+Enter` | 重新整理 | `F5` |
| 圖示檢視 | `Ctrl+1` | 詳細資料檢視 | `Ctrl+2` |
| 分割檢視 | `F3` | 開啟終端機 | `F4` |
| 顯示隱藏檔案 | `Ctrl+H` | 在新分頁中開啟 | 按住 `Ctrl` |


`Ctrl+Shift+T` 會把最後關閉的分頁連同資料夾一起開回來。
## 圖示

- **使用系統檔案圖示** 會向殼層取得每種檔案類型的圖示，而不是內建圖示。
- **使用自訂資料夾圖示** 會保留資料夾以 `desktop.ini` 定義的圖示。
- **依副檔名的圖示** 會把一個副檔名對應到一個內建圖示或圖片檔。
- **資料夾圖示** 可為單一資料夾指定專屬圖示。

## 資料夾索引

每個資料夾可保留一個隱藏的 `.yafm-index.db`，存放圖示、快取大小、標籤與上次的清單，讓下次開啟幾乎
瞬間完成。關閉後資料夾就不會多出檔案，程式改在資料資料夾中保留單一資料庫；通知會說明那是哪個磁碟機。
