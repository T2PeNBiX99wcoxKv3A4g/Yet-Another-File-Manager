# 概覽與相簿

## 概覽

概覽就是首頁：一組面板，可排成一到五欄。左上角的箭頭可改變欄數。按 **編輯** 可重新排列，
按 **完成** 離開編輯模式。

預設面板有：

- **快速存取** — 釘選在側邊欄的資料夾。
- **常用** — 你最常開啟的資料夾，並顯示造訪次數。
- **最近** — 最近開啟的資料夾與檔案。
- **首頁** — 你的主資料夾，以表格或格狀顯示。
- **磁碟機** — 每個已掛載的磁碟區與可用空間。
- **共享** — 此裝置分享的資料夾，以及已配對裝置提供的資料夾。
- **收藏** — 透過右鍵選單的 **加入收藏** 標記的檔案與資料夾。

面板也可以是**資料夾**：選擇任何目錄，就會在原本的位置顯示。

## 編輯面板

在概覽的編輯模式下：

- **新增面板** 會加入任何類型的新面板。
- 圖示按鈕可變更面板圖示。
- 標題會變成文字框；按 `Enter` 或點擊其他地方即可重新命名。
- 釘選按鈕會讓面板同時出現在側邊欄。
- 清單／格狀可切換該面板的版面，箭頭可移動位置，`×` 則移除面板。

箭頭可調整面板順序，版面會存放在設定中。

## 快速存取

快速存取就是側邊欄中的資料夾清單。把資料夾拖到側邊欄即可加入，或使用概覽的編輯模式。在項目上按右鍵
可重新命名、變更圖示或移除；名稱與圖示會依路徑儲存，重新啟動後仍保留。

## 相簿

相簿會掃描[設定](Settings-and-Shortcuts) → 相簿中列出的資料夾，深度三層，並把找到的每張圖片依日期
分組。按兩下磚塊即可開啟，重新整理按鈕可再次掃描。

相簿不會複製或移動任何東西：它只讀取檔案，並把縮圖存放在程式的快取中。在設定中選擇資料夾即可加入；
移除後就不會再掃描。
