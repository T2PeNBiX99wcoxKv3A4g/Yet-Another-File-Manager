# 檔案與檢視

## 分頁

每個分頁都是獨立的資料夾，擁有自己的歷程記錄。使用 `+` 按鈕、`Ctrl+T`，或在資料夾上按滑鼠中鍵即可
開啟。拖曳分頁可調整順序，`Ctrl+W` 或 `×` 可關閉。

關閉的分頁不會消失：`Ctrl+Shift+T` 會在原本的位置重新開啟它。

新分頁會從概覽開始；從資料夾開啟的分頁則會停在該資料夾。

## 分割檢視

按標題列的分割按鈕或 `F3`，即可在下一個檔案分頁旁顯示目前分頁。兩邊可各自瀏覽，分隔線可拖曳，
按兩下可重設寬度。關閉分割檢視時，會保留你正在操作的那個分頁。

## 清單與格狀

標題列的檢視選單可在清單與格狀之間切換，並設定圖示大小（清單）或磚塊高度（格狀）。每個資料夾會
記住上次使用的模式與大小；[設定](Settings-and-Shortcuts)中的數值只是尚未有偏好之資料夾的預設值。

清單採用虛擬化，因此即使資料夾有數萬個項目，捲動時也不會為每個項目建立一列。

## 欄位與排序

點一下欄位標題即可依該欄位排序，再點一次則反轉。檢視選單可選擇要顯示的欄位：類型、大小、修改時間、
建立時間、項目數、連結數、連結狀態與標籤，並可選擇在名稱後顯示連結目標。欄位選擇是全域的，排序方式
則屬於各個資料夾。

拖曳標題右側的分隔線會在該欄位與相鄰欄位之間轉移寬度：整列維持原有寬度，所以不會左右位移，也不會
出現橫向捲動。位於兩端的欄位透過旁邊的分隔線調整。雙擊分隔線會恢復左側欄位的預設寬度。名稱欄位會使用
剩餘空間，因此拖曳名稱的分隔線會壓縮第一個欄位，把空間留給名稱。檢視選單裡 **欄位** 標題旁的
**重設寬度** 可以一次還原所有欄位寬度。

## 預覽面板

圖片、影片、PDF 與文字檔可顯示在清單旁（詳細資料面板）或清單下方（預覽區）。詳細資料面板也會列出
選取項目的大小、日期、連結目標與屬性。影片預覽預設靜音，可在[設定](Settings-and-Shortcuts)中開啟音訊。

## 檔案操作

在檔案、資料夾或空白背景上按右鍵：

- **開啟**、**在新分頁中開啟**、**開啟方式**（包含系統本身的「開啟方式」對話框）。
- **剪下**、**複製**、**貼上**、**貼到資料夾**。
- **重新命名**（`F2`）、**刪除**（`Del`）、**永久刪除**（`Shift+Del`）。
- **新增資料夾**（`Ctrl+Shift+N`，或 `F10`）、**壓縮為 ZIP**、**壓縮到…**、**複製為路徑**。
- **加入收藏**、**加入檔案托盤**、**建立連結**、**大小寫敏感名稱**。
- **在檔案總管中顯示**、**在終端機中開啟**、**屬性**。

刪除預設會把項目移到資源回收筒；永久刪除是另一個動作，可在[設定](Settings-and-Shortcuts)中設為
先詢問。復原與重做涵蓋本次工作階段中的操作。需要系統管理員權限的資料夾會像檔案總管一樣要求
提升權限，同意後繼續完成操作。

壓縮檔在這裡像資料夾一樣開啟，也可以在同一個選單裡解壓縮或建立；見[壓縮檔](Archives)。

**建立連結** 會建立符號連結、檔案的硬式連結或資料夾的目錄連接點。先用 **選擇源連接點** 記住多個路徑，
就能一次為它們建立連結。**大小寫敏感名稱** 會切換該資料夾本身的大小寫敏感設定，對在 Windows 與 Linux
之間搬移檔案的程式有影響。

## 檔案托盤

托盤是一個浮動的架子，用來暫存馬上要貼到別處的內容。把選取的項目拖上去，或使用 **加入檔案托盤**；
標題列的托盤按鈕可以顯示它，並標出其中數量。它也會同步系統剪貼簿，所以在其他應用程式複製的內容也會
出現在這裡。你可以從托盤貼到任何資料夾，也可以把項目拖出來。開始拖曳時它會自動出現；在設定中關閉
**拖曳時開啟檔案托盤** 即可停止，而因拖曳開啟的托盤在沒有任何項目時會自動關閉。

## 歷史與活動

標題列的兩個按鈕會說明應用程式正在做什麼：

- **歷史記錄** 按鈕列出本次工作階段的檔案操作，最新的在最前面，每一列都可以在面板裡復原。
- **活動** 按鈕列出執行中與已完成的背景操作。耗時的刪除或複製會在這裡報告進度，完成的項目可以從
  清單中清除。
