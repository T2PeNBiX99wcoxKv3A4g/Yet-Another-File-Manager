# 分享

## 分享資料夾

標題列的伺服器圖示會開啟此裝置的分享面板：裝置名稱與指紋、正在分享的資料夾，以及把目前資料夾加入的
**分享此資料夾**。每個分享有兩種模式：

- **應用程式**：只有已配對的裝置可以開啟，並且在本應用程式中顯示。
- **網頁**：任何有瀏覽器的裝置都可以開啟。網頁伺服器執行時，面板會列出要輸入的網址。

分享旁的 `×` 會停止分享。概覽的 **共享** 面板會列出此裝置的分享，以及已配對裝置提供的資料夾。

## 配對

兩台裝置配對一次之後，就可以瀏覽彼此的 **應用程式** 分享。配對請求會在兩個畫面上顯示代碼，只有兩邊
代碼一致時才接受。分享面板裡的裝置名稱與指紋可以確認請求來自哪台裝置。

## 網頁伺服器

連接埠在[設定](Settings-and-Shortcuts)的 **網頁伺服器連接埠** 中選擇：*隨機* 會在第一次網頁分享時向
系統取得一個空閒連接埠並持續使用，*自訂連接埠* 則一律嘗試你設定的號碼。網頁分享只在應用程式執行期間、
並且只有同一網路中的裝置可以開啟。
