# 搜尋、標籤與資源回收筒

## 搜尋

`Ctrl+F` 會在目前資料夾上開啟浮動搜尋列。它會隨輸入即時過濾；在資料夾上直接輸入字母也會開啟。

- `Enter` 跳到下一個符合項，`Shift+Enter` 跳到上一個。
- **Aa** 區分大小寫，`.*` 會把查詢當成規則運算式。
- 模式按鈕可在 **變暗**（不符的列淡化）與 **隱藏**（直接消失）之間切換。
- `Esc` 關閉搜尋列並還原資料夾。

搜尋只會查看畫面上的資料夾，不會進入子資料夾。

## 標籤

標籤依資料夾儲存在該資料夾的索引中，而[設定](Settings-and-Shortcuts) → 標籤中的目錄會列出程式
看過的所有標籤。

- 點一下某列的標籤欄，或使用詳細資料面板中的標籤按鈕，即可開啟選擇器。
- 勾選想要的標籤、在文字框新增標籤，並為每個標籤選擇顏色。
- 在目錄中重新命名或移除標籤，會更新所有使用該標籤的資料夾。
- 標籤顏色會記在設定它的資料夾中，因此同一個標籤在不同資料夾可以有不同的顏色。

## 資源回收筒

資源回收筒讀取系統本身的回收筒：Windows 的資源回收筒，或 Linux 的 freedesktop 回收筒。

- **還原** 會把選取的項目放回原來的位置。
- **刪除** 會永久移除選取的項目；**清空** 會清空整個回收筒。
- **孤兒項目** 開關會顯示檔案本體已不存在的記錄，可再將其移除。
- **顯示全部 (管理員)** 會要求管理員權限，並列出所有使用者設定檔的殘留項目；未開啟時只顯示你自己的項目。

只有在原始資料夾仍存在時才能還原；否則項目會留在回收筒，該列也會說明原因。從資源回收筒刪除後無法復原。
