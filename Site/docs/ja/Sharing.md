# 共有

## フォルダーを共有する

タイトルバーのサーバーアイコンで、この端末の共有パネルが開きます。端末名とフィンガープリント、
共有しているフォルダー、そして表示中のフォルダーを渡す **このフォルダーを共有** があります。共有には
2 つのモードがあります。

- **アプリ**: ペアリング済みの端末だけが開け、このアプリで表示します。
- **Web**: ブラウザーがある端末ならどれでも開けます。Web サーバーの実行中は、入力するアドレスが
  パネルに並びます。

共有の横の `×` で提供を止めます。概要の **共有** パネルには、この端末の共有と、ペアリングした端末が
提供しているフォルダーが並びます。

## ペアリング

2 台の端末は一度ペアリングすると、互いの **アプリ** 共有を閲覧できます。ペアリングの要求では両方の画面に
コードが表示されるので、2 つのコードが一致したときだけ承認してください。共有パネルの端末名と
フィンガープリントで、要求してきた端末を確認できます。

## Web サーバー

ポートは [設定](Settings-and-Shortcuts) の **Web サーバーのポート** で決めます。*ランダム* は最初の
Web 共有のときに OS から空きポートを得てそのまま使い、*カスタムポート* は設定した番号を常に使います。
Web 共有はアプリの実行中だけ、同じネットワークから開けます。
