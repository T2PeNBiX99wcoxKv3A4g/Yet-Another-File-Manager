# 概要とギャラリー

## 概要

概要はホーム画面で、1〜5 列に並べたパネルの集まりです。左上の矢印で列数を変えます。**編集** を押すと
並べ替えモードになり、**完了** で抜けます。

既定のパネルは次のとおりです。

- **クイックアクセス** — サイドバーにピン留めしたフォルダー。
- **よく使う** — 最もよく開くフォルダーとアクセス回数。
- **最近** — 最近開いたフォルダーとファイル。
- **ホーム** — ホームフォルダーを表またはグリッドで表示。
- **ドライブ** — マウントされた各ボリュームと空き容量。
- **共有** — この端末が共有しているフォルダーと、ペアリングした端末が提供しているフォルダー。詳しくは
  [共有](Sharing)を参照してください。
- **お気に入り** — 右クリックメニューの **お気に入りに追加** で印を付けたファイルとフォルダー。

パネルは**フォルダー**にもできます。任意のディレクトリを選ぶと、その場所に表示されます。

## パネルの編集

概要が編集モードのとき:

- **パネルを追加** で任意の種類のパネルを追加します。
- アイコンボタンでパネルのアイコンを変えます。
- タイトルはテキストボックスになり、`Enter` または外側のクリックで名前を変更します。
- ピンボタンでサイドバーにも表示します。
- リスト／グリッドでそのパネルの表示を切り替え、矢印で移動、`×` で削除します。

矢印でパネルの順序を変えられ、レイアウトは設定に保存されます。**既定のパネルに戻す** は、タイトル・
アイコン・ピン留めも含めて、すべてのパネルを出荷時の状態に戻します。

## クイックアクセス

クイックアクセスはサイドバーのフォルダー一覧です。フォルダーをサイドバーにドラッグするか、概要の編集
モードで追加します。項目を右クリックすると名前の変更、アイコンの変更、削除ができます。名前とアイコンは
パスごとに保存され、再起動後も残ります。

## ギャラリー

ギャラリーは[設定](Settings-and-Shortcuts) → ギャラリーに登録したフォルダーを 3 階層までスキャンし、
見つけた画像を日付ごとにまとめます。タイルをダブルクリックすると開き、更新ボタンで再スキャンします。

ファイルのコピーや移動は行いません。読み取った内容とサムネイルをアプリのキャッシュに保存するだけです。
設定でフォルダーを追加すれば対象になり、削除すれば以後スキャンしません。
