# 設定とショートカット

設定は変更するとすぐ保存されます。保存ボタンはありません。設定はインターフェースの言語や最後に開いて
いたタブと一緒に、アプリの設定フォルダーに保存されます。左の一覧から各項目へ移動できます。

## アプリケーション

- **バージョン**、**プラットフォーム**、**ログ** — ビルド、対象のランタイム、ログフォルダーを開く
  ボタン。
- **言語** はインターフェースをすぐに切り替えます。*システム既定* は OS に従い、既定は英語です。
- **ピッカーウィンドウのサイズ** — フォルダーとファイルのピッカーが開く大きさ（ピクセル）。
- **Web サーバーのポート** — *ランダム* は最初の Web 共有のときに OS から空きポートを得てそのまま
  使い、*カスタムポート* は下の番号を常に使います。
- **リンクのパス** — 相対パスはリンクと対象が一緒に移動しても壊れません。絶対パスは常に対象の完全な
  パスを保存します。
- **グローバルホットキー** はアプリの実行中、どこからでもウィンドウを前面に出します。
- **yafm:// リンクを開く**、**既定のファイルマネージャーとして使う**、**このアプリでアーカイブを開く**
  は、このアカウントでリンク・フォルダー・アーカイブをこのアプリに登録します。最初の 2 つはオンに
  している間、起動のたびに登録を修復します。
- **以前開いていたタブを復元** はタブとそれぞれのフォルダーを復元します。コマンドラインで指定した
  フォルダーが優先されます。

## スタートアップ

**コンピューター起動時に開始** はログイン項目に追加し、**トレイで非表示のまま起動** は開くまで
ウィンドウを出しません。

## フォントと時刻

インターフェースの各部分にそれぞれフォントを選べます。インストール済みのフォントが一覧され、どれも
その書体で表示されます。**時刻の形式** はシステムに従うか、24 時間制・12 時間制を強制するか、独自の
パターンを指定できます。

## アップデート

実行中のバージョン、公開されている最新版、そして **アップデートを確認**。

## 色と背景

- **プリセット** はアクセント色とセカンダリ色を同時に適用します。8 種類が組み込まれています。
  **プリセットを追加** は現在の組み合わせを名前付きで保存し、`×` で保存したものを削除します。
  プリセットは翻訳されません。
- **アクセントカラー** と **セカンダリカラー** は任意の色を選べます。色見本の横に最近使った色が並び、
  すぐ戻せます。**色をリセット** で既定のブルーとインディゴに戻ります。
- **壁紙** はファイルか URL から画像や動画をウィンドウ全体の背景に敷きます。**ぼかし**、**彩度**、
  **明るさ** で調整できます。

## セーフティ

**保護フォルダー**、その中の項目、または保護フォルダーを含むフォルダーを削除するときは、必ず明示的な
確認を待ちます。**確認の待ち時間** は、その確認を受け付けられるようになるまでの時間です。

## タグ

すべてのタグの一覧です。追加、名前の変更、色の変更、使っているすべてのフォルダーからの削除ができます。
タグの付け方は[検索・タグ・ごみ箱](Search-Tags-Recycle)にあります。

## ファイル表示

まだ独自の表示を保存していないフォルダーに対する既定値です。

- 既定のモード（リスト／グリッド）、リストのアイコンサイズ、グリッドタイルの高さ。
- **選択チェックボックス**、**シングルクリックで開く**、**削除前に確認**。
- **動画プレビューで音声を再生**、**動画プレビューを自動再生**。
- **リスト下のプレビューパネル**、表示する**列**。
- **リセット** でこのページを出荷時の値に戻します。

フォルダーはタイトルバーから独自のモード、サイズ、並び順を覚えます。*グローバル* と付いたスイッチは
すべてのフォルダーに適用されます。

## ショートカット

組み合わせをクリックすると新しいものを記録でき、**リセット** ですべて既定に戻ります。既定値は次の
とおりです。

| 操作 | キー | 操作 | キー |
| --- | --- | --- | --- |
| 戻る | `Alt+←` | 進む | `Alt+→` |
| 上の階層へ | `Alt+↑` | ホームフォルダー | `Alt+Home` |
| 検索 | `Ctrl+F` | 場所を編集 | `Ctrl+L` |
| 新しいタブ | `Ctrl+T` | タブを閉じる | `Ctrl+W` |
| 次のタブ | `Ctrl+Tab` | 前のタブ | `Ctrl+Shift+Tab` |
| 閉じたタブを開き直す | `Ctrl+Shift+T` | 新しいタブで開く | `Ctrl` を押しながら |
| コピー | `Ctrl+C` | 切り取り | `Ctrl+X` |
| 貼り付け | `Ctrl+V` | 元に戻す | `Ctrl+Z` |
| やり直し | `Ctrl+Shift+Z` | すべて選択 | `Ctrl+A` |
| 選択を反転 | `Ctrl+Shift+A` | 開く | `Enter` |
| 新しいフォルダー | `Ctrl+Shift+N` | 名前の変更 | `F2` |
| ごみ箱に移動 | `Del` | 完全に削除 | `Shift+Del` |
| プロパティ | `Alt+Enter` | アイコン表示 | `Ctrl+1` |
| 詳細表示 | `Ctrl+2` | 分割表示 | `F3` |
| ターミナルを開く | `F4` | 隠しファイルを表示 | `Ctrl+H` |

## メモリ

このページにはプロセスメモリとマネージドヒープが表示されます。**今すぐ整理** はヒープを圧縮し、
未使用のページをシステムに返します。

## 概要とギャラリー

- **最近の項目** は概要に並べる最近開いたフォルダーの数です。0 にするとそのセクションは消えます。
- **フォルダーをスキャン** はギャラリーが読むフォルダーで、3 階層までです。何も追加していないときは
  ピクチャフォルダーを読みます。パネルの説明は[概要とギャラリー](Overview-and-Gallery)にあります。

## アイコン

- **システムのファイルアイコンを使う** は、組み込みグリフの代わりにシェルから種類ごとのアイコンを取得
  します。
- **カスタムフォルダーアイコンを使う** は、フォルダーが `desktop.ini` で定義したアイコンを保持します。
- **拡張子ごとのアイコン** は 1 つの拡張子を組み込みアイコンまたは画像ファイルに対応付けます。
- **フォルダーアイコン** は 1 つのフォルダーに専用アイコンを設定します。

## フォルダーインデックス

各フォルダーは隠しファイル `.yafm-index.db` にアイコン、キャッシュしたサイズ、タグ、前回の一覧を
保持でき、次回はほぼ一瞬で開きます。オフにするとフォルダーに余分なファイルを作らず、代わりにデータ
フォルダーの 1 つのデータベースを使います。ブラックリストの規則は選んだフォルダーにインデックスを
作らせないようにし、通知にデータベースのあるドライブが表示されます。

## インデックスタスク

フォルダーのサイズと項目数を測るバックグラウンドの走査です。作業中のフォルダーが表示され、ここから
停止できます。

## ファイル

**非表示の項目** と **保護されたオペレーティングシステムファイル** はファイルマネージャー自身の設定に
従い、OS が表示する設定のときだけ一覧に出ます。`Ctrl+H` はそのセッションの通常の隠しファイルを
切り替えます。システムファイルはエクスプローラーの設定に従います。
