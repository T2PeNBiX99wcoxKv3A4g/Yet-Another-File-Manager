# 設定とショートカット

設定は変更するとすぐ保存されます。保存ボタンはありません。設定はインターフェースの言語や最後に開いて
いたタブと一緒に、アプリの設定フォルダーに保存されます。

## アプリケーション

- **バージョン** と **プラットフォーム** は読み取り専用です。
- **言語** はインターフェースをすぐに切り替えます。*システム既定* は OS に従い、既定は英語です。
- **yafm:// リンクを開く** は現在のユーザーに `yafm://` リンクを登録し、オンの間は起動のたびに登録を
  修復します。
- **以前開いていたタブを復元** はタブとそれぞれのフォルダーを復元します。コマンドラインで指定した
  フォルダーが優先されます。

## 色

- **プリセット** はアクセント色とセカンダリ色を同時に適用します。8 種類が組み込まれています。
- **プリセットを追加** は現在の組み合わせを名前付きで保存します。`×` で保存したプリセットを削除します。
  プリセットは設定ファイルに保存され、翻訳されません。
- **アクセントカラー** と **セカンダリカラー** は任意の色を選べます。色見本の横に最近使った色が並び、
  すぐ戻せます。
- **色をリセット** で既定のブルーとインディゴに戻ります。

## ファイル表示

まだ独自の表示を保存していないフォルダーに対する既定値です。

- 既定のモード（リスト／グリッド）、リストのアイコンサイズ、グリッドタイルの高さ。
- **選択チェックボックス**、**シングルクリックで開く**、**削除前に確認**。
- **動画プレビューで音声を再生**、**動画プレビューを自動再生**。
- **リスト下のプレビューパネル**、表示する**列**。

フォルダーはタイトルバーから独自のモード、サイズ、並び順を覚えます。*グローバル* と付いたチェック
ボックスやスイッチはすべてのフォルダーに適用されます。

## ショートカット

組み合わせをクリックすると新しいものを記録でき、**リセット** ですべて既定に戻ります。既定値は次の
とおりです。

| 操作 | キー | 操作 | キー |
| --- | --- | --- | --- |
| 戻る | `Alt+←` | 進む | `Alt+→` |
| 上の階層へ | `Alt+↑` | ホームフォルダー | `Alt+Home` |
| 検索 | `Ctrl+F` | 場所を編集 | `Ctrl+L` |
| 新しいタブ | `Ctrl+T` | タブを閉じる | `Ctrl+W` |
| 次のタブ | `Ctrl+Tab` | 前のタブ | `Ctrl+Shift+Tab` |
| コピー | `Ctrl+C` | 切り取り | `Ctrl+X` |
| 貼り付け | `Ctrl+V` | 元に戻す | `Ctrl+Z` |
| やり直し | `Ctrl+Shift+Z` | すべて選択 | `Ctrl+A` |
| 選択を反転 | `Ctrl+Shift+A` | 開く | `Enter` |
| 新しいフォルダー | `Ctrl+Shift+N` | 名前の変更 | `F2` |
| ごみ箱に移動 | `Del` | 完全に削除 | `Shift+Del` |
| プロパティ | `Alt+Enter` | 更新 | `F5` |
| アイコン表示 | `Ctrl+1` | 詳細表示 | `Ctrl+2` |
| 分割表示 | `F3` | ターミナルを開く | `F4` |
| 隠しファイルを表示 | `Ctrl+H` | 新しいタブで開く | `Ctrl` を押しながら |


`Ctrl+Shift+T` で、最後に閉じたタブをフォルダーごと開き直せます。
## アイコン

- **システムのファイルアイコンを使う** は、組み込みグリフの代わりにシェルから種類ごとのアイコンを取得
  します。
- **カスタムフォルダーアイコンを使う** は、フォルダーが `desktop.ini` で定義したアイコンを保持します。
- **拡張子ごとのアイコン** は 1 つの拡張子を組み込みアイコンまたは画像ファイルに対応付けます。
- **フォルダーアイコン** は 1 つのフォルダーに専用アイコンを設定します。

## フォルダーインデックス

各フォルダーは隠しファイル `.yafm-index.db` にアイコン、キャッシュしたサイズ、タグ、前回の一覧を
保持でき、次回はほぼ一瞬で開きます。オフにするとフォルダーに余分なファイルを作らず、代わりにデータ
フォルダーの 1 つのデータベースを使います。通知にそのドライブが表示されます。
