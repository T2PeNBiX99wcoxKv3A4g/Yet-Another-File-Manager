# ファイルと表示

## タブ

各タブは独自の履歴を持つフォルダーです。`+` ボタン、`Ctrl+T`、またはフォルダー上でマウス中ボタンを
押すと開きます。タブをドラッグすると並べ替えられ、`Ctrl+W` または `×` で閉じます。

閉じたタブは消えません。`Ctrl+Shift+T` で元の場所に開き直せます。

新しいタブは概要から始まり、フォルダーから開いたタブはそのフォルダーを表示します。

## 分割表示

タイトルバーの分割ボタンまたは `F3` で、次のファイルタブを現在のタブの隣に表示します。左右は独立して
移動でき、仕切りはドラッグで調整、ダブルクリックで幅を戻せます。分割表示を閉じても、操作していたタブは
残ります。

## リストとグリッド

タイトルバーの表示メニューでリストとグリッドを切り替え、アイコンサイズ（リスト）またはタイルの高さ
（グリッド）を設定します。フォルダーは前回のモードとサイズを覚えます。[設定](Settings-and-Shortcuts)の
値は、まだ設定を持たないフォルダーの既定値です。

リストは仮想化されているため、数万件のフォルダーでも全行を描画せずにスクロールできます。

## 列と並べ替え

列見出しをクリックするとその列で並べ替え、もう一度クリックすると逆順になります。表示メニューで表示する
列を選べます（種類、サイズ、更新日時、作成日時、項目数、リンク数、リンク状態、タグ。名前の後にリンク先を
表示するオプションも）。列の選択は全体設定、並び順はフォルダーごとの設定です。

## プレビューパネル

画像、動画、PDF、テキストはリストの横（詳細パネル）または下（プレビュー領域）に表示できます。詳細
パネルには選択項目のサイズ、日時、リンク先、属性も出ます。動画プレビューは既定でミュートで、
[設定](Settings-and-Shortcuts)で音声を有効にできます。

## ファイル操作

ファイル、フォルダー、または何もない背景を右クリックします。

- **開く**、**新しいタブで開く**、**プログラムから開く**（シェル自身のダイアログも含む）。
- **切り取り**、**コピー**、**貼り付け**、**フォルダーに貼り付け**。
- **名前の変更**（`F2`）、**削除**（`Del`）、**完全に削除**（`Shift+Del`）。
- **新しいフォルダー**（`Ctrl+Shift+N`、または `F10`）、**ZIP に圧縮**、**圧縮先…**、**パスとしてコピー**。
- **お気に入りに追加**、**ファイルトレイに追加**、**リンクを作成**、**大文字と小文字を区別する名前**。
- **エクスプローラーで表示**、**ターミナルで開く**、**プロパティ**。

削除は既定でごみ箱に移動します。完全削除は別の操作で、[設定](Settings-and-Shortcuts)で確認するように
できます。元に戻す／やり直しは現在のセッションの操作が対象です。

アーカイブはここでフォルダーとして開き、同じメニューから展開や作成ができます。詳しくは
[アーカイブ](Archives)を参照してください。

**リンクを作成** はシンボリックリンク、ファイルのハードリンク、フォルダーのディレクトリ ジャンクション
を作ります。先に **リンク元を選択** で複数のパスを覚えておけば、まとめてリンクを作れます。
**大文字と小文字を区別する名前** はそのフォルダー自身の大文字小文字の区別を切り替えます。Windows と
Linux の間でファイルを移すプログラムでは、この設定が影響します。

## ファイルトレイ

トレイは、これから別の場所に貼り付けるものを載せておく浮いた棚です。選択をドラッグして載せるか、
**ファイルトレイに追加** を使います。タイトルバーのトレイボタンで表示でき、入っている数も表示されます。
システムのクリップボードも反映されるので、他のアプリでコピーしたものもここに現れます。トレイから
どのフォルダーにも貼り付けでき、項目を外へドラッグして取り出すこともできます。

## 履歴とアクティビティ

タイトルバーの 2 つのボタンが、アプリの動作を伝えます。

- **履歴** ボタンはこのセッションのファイル操作を新しい順に並べ、各行からパネル内で元に戻せます。
- **アクティビティ** ボタンは実行中と完了したバックグラウンド操作を並べます。時間のかかる削除や
  コピーはここで進捗を報告し、完了した項目は一覧から消せます。
