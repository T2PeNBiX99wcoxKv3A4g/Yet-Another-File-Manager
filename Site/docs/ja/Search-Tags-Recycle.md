# 検索、タグ、ごみ箱

## 検索

`Ctrl+F` で現在のフォルダーにフローティング検索バーが開きます。入力しながら絞り込み、フォルダーに文字を
入力しても開きます。

- `Enter` で次の一致、`Shift+Enter` で前の一致へ移動します。
- **Aa** で大文字と小文字を区別し、`.*` でクエリを正規表現として扱います。
- モードボタンで **淡色**（一致しない行を薄く表示）と **非表示**（消す）を切り替えます。
- `Esc` で検索バーを閉じ、フォルダーを元に戻します。

検索は画面のフォルダーだけを対象にし、サブフォルダーには入りません。

## タグ

すべてのタグは 1 つのグローバルなカタログにあり、それぞれに色があります。フォルダーのインデックス
にはタグの id だけが保存されるため、名前や色の変更はどこでも一度に反映されます。

- 行のタグセルをクリックすると選択画面が開き、カタログのすべてのタグが並びます。
- 使うタグにチェックを入れます。テキストボックスに新しい名前を入力すると、隣の色でタグが作られます。
- [設定](Settings-and-Shortcuts) → タグがカタログです。追加、名前の変更、色の変更、使用中のすべての
  フォルダーからの削除ができます。
- 色はフォルダーではなくタグに属するため、どのフォルダーでも同じ見た目になります。

## ごみ箱

ごみ箱はシステム自身のもの（Windows のごみ箱、Linux の freedesktop ごみ箱）を読み取ります。

- **復元** で選択項目を元の場所へ戻します。
- **削除** で選択項目を完全に削除し、**空にする** でごみ箱全体を空にします。
- **孤立項目** スイッチで、本体がすでにないレコードを表示し、削除できます。
- **すべて表示 (管理者)** は管理者権限を要求し、すべてのユーザープロファイルの残りを一覧します。
  オフのときは自分の項目だけです。

元のフォルダーが残っている場合だけ復元できます。残っていない場合はごみ箱に残り、その理由が行に表示
されます。ごみ箱からの削除は元に戻せません。
