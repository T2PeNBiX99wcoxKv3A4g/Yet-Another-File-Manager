# 文件与视图

## 标签页

每个标签页都是独立的文件夹，拥有自己的历史记录。使用 `+` 按钮、`Ctrl+T`，或在文件夹上按鼠标中键即可
打开。拖动标签页可调整顺序，`Ctrl+W` 或 `×` 可关闭。

关闭的标签页不会消失：`Ctrl+Shift+T` 会在原来的位置重新打开它。

新标签页会从概览开始；从文件夹打开的标签页则会停在该文件夹。

## 分屏视图

按标题栏的分屏按钮或 `F3`，即可在下一个文件标签页旁显示当前标签页。两边可各自浏览，分隔线可拖动，
双击可重置宽度。关闭分屏视图时会保留你正在操作的那个标签页。

## 列表与网格

标题栏的视图菜单可在列表与网格之间切换，并设置图标大小（列表）或磁贴高度（网格）。每个文件夹会记住
上次使用的模式和大小；[设置](Settings-and-Shortcuts)中的数值只是尚未有偏好之文件夹的默认值。

列表采用虚拟化，因此即使文件夹有数万个项目，滚动时也不会为每个项目创建一行。

## 列与排序

单击列标题即可按该列排序，再点一次则反转。视图菜单可选择要显示的列：类型、大小、修改时间、创建时间、
项目数、链接数、链接状态和标签，并可选择在名称后显示链接目标。列的选择是全局的，排序方式则属于各个
文件夹。

拖动标题右侧的分隔线会在该列与相邻列之间转移宽度：整行保持原有宽度，所以不会左右位移，也不会出现
横向滚动。位于两端的列通过旁边的分隔线调整。双击分隔线会恢复左侧列的默认宽度。名称列会占用剩余空间，
因此拖动名称的分隔线会压缩第一列，把空间留给名称。视图菜单里 **列** 标题旁的 **重置宽度** 可以一次性恢复
所有列宽。

## 预览面板

图片、视频、PDF 和文本文件可显示在列表旁（详细信息面板）或列表下方（预览区）。详细信息面板也会列出
选中项目的大小、日期、链接目标和属性。视频预览默认静音，可在[设置](Settings-and-Shortcuts)中开启音频。

## 文件操作

在文件、文件夹或空白背景上右键：

- **打开**、**在新标签页中打开**、**打开方式**（包含系统本身的“打开方式”对话框）。
- **剪切**、**复制**、**粘贴**、**粘贴到文件夹**。
- **重命名**（`F2`）、**删除**（`Del`）、**永久删除**（`Shift+Del`）。
- **新建文件夹**（`Ctrl+Shift+N`，或 `F10`）、**压缩为 ZIP**、**压缩到…**、**复制为路径**。
- **添加到收藏**、**添加到文件托盘**、**创建链接**、**大小写敏感名称**。
- **在资源管理器中显示**、**在终端中打开**、**属性**。

删除默认会把项目移到回收站；永久删除是另一个操作，可在[设置](Settings-and-Shortcuts)中设为先询问。
撤销与重做涵盖本次会话中的操作。

压缩包在这里像文件夹一样打开，也可以在同一个菜单里解压或创建；见[压缩包](Archives)。

**创建链接** 会建立符号链接、文件的硬链接或文件夹的目录联接点。先用 **选择源连接点** 记住多个路径，
就能再一次为它们建立链接。**大小写敏感名称** 会切换该文件夹自身的大小写敏感设置，对在 Windows 与
Linux 之间搬运文件的程序有影响。

## 文件托盘

托盘是一个浮动的架子，用来暂存马上要粘贴到别处的内容。把选中的项目拖上去，或使用 **添加到文件托盘**；
标题栏的托盘按钮可以显示它，并标出其中数量。它也会同步系统剪贴板，所以在其他应用里复制的内容也会
出现在这里。你可以从托盘粘贴到任何文件夹，也可以把项目拖出来。

## 历史与活动

标题栏的两个按钮会说明应用正在做什么：

- **历史记录** 按钮列出本次会话的文件操作，最新的在最前，每一行都可以在面板里撤销。
- **活动** 按钮列出运行中和已完成的背景操作。耗时的删除或复制会在这里报告进度，完成的项目可以从
  列表中清除。
