# 概览与图库

## 概览

概览就是主页：一组面板，可排成一到五列。左上角的箭头可改变列数。按 **编辑** 可重新排列，
按 **完成** 离开编辑模式。

默认面板有：

- **快速访问** — 固定在侧边栏的文件夹。
- **常用** — 你最常打开的文件夹，并显示访问次数。
- **最近** — 最近打开的文件夹和文件。
- **主文件夹** — 你的主文件夹，以表格或网格显示。
- **驱动器** — 每个已挂载的驱动器及其可用空间。
- **共享** — 此设备共享的文件夹，以及已配对设备提供的文件夹；见[共享](Sharing)。
- **收藏** — 通过右键菜单的 **添加到收藏** 标记的文件和文件夹。

面板也可以是**文件夹**：选择任何目录，就会在原来的位置显示。

## 编辑面板

在概览的编辑模式下：

- **添加面板** 会加入任何类型的新面板。
- 图标按钮可更改面板图标。
- 标题会变成文本框；按 `Enter` 或点击其他位置即可重命名。
- 固定按钮会让面板同时出现在侧边栏。
- 列表/网格可切换该面板的布局，箭头可移动位置，`×` 则移除面板。

箭头可调整面板顺序，布局会保存在设置中。**恢复默认面板** 会把所有面板恢复为应用出厂时的状态，包括
标题、图标与固定状态。

## 快速访问

快速访问就是侧边栏中的文件夹列表。把文件夹拖到侧边栏即可加入，或使用概览的编辑模式。在项目上右键
可重命名、更改图标或移除；名称和图标会按路径保存，重启后仍然保留。

## 图库

图库会扫描[设置](Settings-and-Shortcuts) → 图库中列出的文件夹，深度三层，并把找到的每张图片按日期
分组。双击磁贴即可打开，刷新按钮可再次扫描。

图库不会复制或移动任何东西：它只读取文件，并把缩略图存放在程序的缓存中。在设置中选择文件夹即可加入；
移除后就不会再扫描。
