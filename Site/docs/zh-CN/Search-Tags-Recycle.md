# 搜索、标签与回收站

## 搜索

`Ctrl+F` 会在当前文件夹上打开浮动搜索栏。它会随输入即时过滤；在文件夹上直接输入字母也会打开。

- `Enter` 跳到下一个匹配项，`Shift+Enter` 跳到上一个。
- **Aa** 区分大小写，`.*` 会把查询当作正则表达式。
- 模式按钮可在 **变暗**（不匹配的行淡化）与 **隐藏**（直接消失）之间切换。
- `Esc` 关闭搜索栏并恢复文件夹。

搜索只查看屏幕上的文件夹，不会进入子文件夹。

## 标签

所有标签都放在同一个全局目录中，每个标签都有自己的颜色。文件夹的索引只存储标签的 id，因此重命名
或改色会一次应用到所有地方。

- 单击某一行的标签单元格即可打开选择器，里面会列出目录中的所有标签。
- 勾选想要的标签；在文本框中输入新名称，就会用旁边的颜色创建一个新标签。
- [设置](Settings-and-Shortcuts) → 标签就是目录：可添加、重命名、改色，或从所有使用它的文件夹移除。
- 标签在任何文件夹看起来都一样，因为颜色属于标签本身，而不是文件夹。

## 回收站

回收站读取系统本身的回收站：Windows 的回收站，或 Linux 的 freedesktop 回收站。

- **还原** 会把选中的项目放回原来的位置。
- **删除** 会永久移除选中的项目；**清空** 会清空整个回收站。
- **孤立项** 开关会显示文件本体已不存在的记录，可再将其移除。
- **显示全部 (管理员)** 会请求管理员权限，并列出所有用户配置文件的残留项；未开启时只显示你自己的项目。

只有在原始文件夹仍然存在时才能还原；否则项目会留在回收站，该行也会说明原因。从回收站删除后无法撤销。
