# 共享

## 共享文件夹

标题栏的服务器图标会打开此设备的共享面板：设备名称与指纹、正在共享的文件夹，以及把当前文件夹加进去的
**共享此文件夹**。每个共享有两种模式：

- **应用**：只有已配对的设备可以打开，并且在本应用中显示。
- **网页**：任何有浏览器的设备都可以打开。网页服务器运行时，面板会列出要输入的地址。

共享旁边的 `×` 会停止共享。概览的 **共享** 面板会列出此设备的共享，以及已配对设备提供的文件夹。

## 配对

两台设备配对一次之后，就可以浏览彼此的 **应用** 共享。配对请求会在两个屏幕上显示代码，只有两边代码
一致时才接受。共享面板里的设备名称与指纹可以确认请求来自哪台设备。

## 网页服务器

端口在[设置](Settings-and-Shortcuts)的 **网页服务器端口** 中选择：*随机* 会在第一次网页分享时向系统
申请一个空闲端口并一直使用，*自定义端口* 则始终尝试你设置的号码。网页共享只在应用运行期间、并且只有
同一网络中的设备可以打开。
