# Sharing

## Sharing a folder

The server icon in the title bar opens this device's share panel: its name and fingerprint, the
folders it offers, and **Share this folder** for the folder on screen. Each share has one of two
modes:

- **App**: only devices paired with this one can open the folder, and they open it in this app.
- **Web**: any device with a browser can open it. While the web server runs, the panel lists the
  addresses to type in.

The `×` beside a share stops offering it. The overview's **Shared** panel lists the shares of this
device together with the folders the paired devices offer.

## Pairing

Two devices pair once and can then browse each other's **App** shares. A pairing request shows a code
on both screens; accept it only when the two codes match. The name and fingerprint in the share panel
identify the device that asks.

## The web server

**Web server port** in [Settings](Settings-and-Shortcuts) chooses the port: *Random* asks the operating
system for a free one when the first web share starts and keeps using it, while *Custom port* always
tries the number you set. A web share is only reachable while the app is running, and from the same
network.
